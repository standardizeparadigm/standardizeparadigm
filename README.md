Xin chào 👋 Mình là **Standardize Paradigm** — **học sinh lớp 7** tại Long Xuyên, An Giang, Việt Nam, và mình học code vì **nó vui thật sự**.

Mọi thứ bắt đầu từ một dòng `print("Hello World")`. Rồi mình nhận ra: **học được 1 thứ sẽ mở ra 10 thứ muốn thử** — nên bây giờ mình vừa code, vừa tò mò **cực kỳ nhiều thứ khác** 🚀 Mình tự học qua các tài liệu tiếng Anh, mày mò bản dịch, sai rồi sửa, rồi lại viết lại cho sạch hơn.

```yaml
name:       Standardize Paradigm
role:       Học sinh lớp 7 • Lập trình viên tự học
location:   Long Xuyên, An Giang, Việt Nam (UTC+7)
learning:   [Python, JavaScript, Web, "mọi thứ trông thú vị"]
superpower: Học nhanh + không sợ code lỗi
fun_fact:   Bug đầu tiên mình fix mất 3 tiếng — và mình vẫn nhớ nó đến ngày hôm nay
motto:      "Cứ thử đi, sai thì học được nhiều hơn"
```

- 🌱 &nbsp;**Đang học:** Python, JavaScript, HTML/CSS và tự làm web nho nhỏ
- 🛠️ &nbsp;**Đang xây:** game mini, tool tiện tay, vài project "để cho vui"
- 🎯 &nbsp;**Mục tiêu năm nay:** 3 project tử tế + code sạch hơn + đóng góp 1 pull request open-source
- 💬 &nbsp;**Hỏi mình về:** Python, HTML/CSS, cách bắt đầu code khi còn đi học
- 🤝 &nbsp;**Muốn tìm:** bạn cùng tuổi để làm project chung, học lẫn nhau
- ⚡ &nbsp;**Sự thật:** mình đọc docs tiếng Anh dù đôi lúc phải tra từ điển từng câu

## 🗓️ &nbsp;06 — Lộ trình & thành tựu

<div align="center">

| Thời gian | Sự kiện | Chi tiết |
| :-- | :-- | :-- |
| Hiện tại | 🏗️ Đang tự học web | HTML/CSS responsive, Flexbox, JavaScript tương tác |
| Gần đây | 🐍 Hoàn thành Python cơ bản | Biến, vòng lặp, hàm, list, dict, chia file nhỏ |
| Tháng trước | 🌐 Cuốn cuối cùng cũng căn giữa được div | Flexbox, margin: auto, grid cơ bản |
| 3 tháng trước | 🔧 Git: commit, branch, push | Sửa khi push sai, làm quen PR |
| 6 tháng trước | 🐍 Python đầu tiên | `print("Hello World")`, biến, if/else |
| Năm ngoái | 🧩 Scratch | Kéo thả logic, vòng lặp đầu tiên |

</div>

### 🏆 Thành tựu nhỏ nhưng ý nghĩa

- 🐞 Fix được bug đầu tiên sau 3 tiếng mày mò — và ghi nhớ bài học đó
- 📦 Đẩy project đầu tiên lên GitHub với commit/triển khai tử tế
- 🌿 Tự làm quen với branch và pull request
- 📚 Đọc tài liệu tiếng Anh dù đôi lúc phải tra từ điển từng câu
- 🤝 Muốn tìm bạn cùng tuổi để làm project chung, học lẫn nhau
